## 🌟 О программе

**DeepNight DSP** — это высокопроизводительный мультиплатформенный 15-полосный аудиопроцессор студийного класса на базе нативного **C++20 ядра**, разработанный для **Android TV**, **Linux Desktop (PipeWire / PulseAudio)** и **Windows Desktop (WASAPI Loopback)**.

Программа кардинально улучшает звучание любых колонок, саундбаров и наушников благодаря субмиллисекундной фильтрации частот в реальном времени.

## 🆓 Что доступно БЕСПЛАТНО и БЕССРОЧНО (FREE-версия):
Даже когда тестовый период истекает, приложение **НЕ заблокируется** и продолжит работать:
1. **Основной переключатель DSP-эффектов** (`DSP Эффекты: Вкл / Выкл`).
2. **Базовый сброс на 0 дБ** (плоская чистая АЧХ).
3. **Автозапуск вместе с системой** при включении ПК или ТВ.
4. **Фоновый защищенный сервис/демон обработки звука**.
5. **Спектроанализатор спектра в реальном времени**.
