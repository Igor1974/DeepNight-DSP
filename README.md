## 🌟 О программе

**DeepNight DSP** — это автономный 15-полосный аудиопроцессор студийного класса, разработанный специально для Android TV, смарт-телевизоров и ТВ-приставок. Программа кардинально улучшает звучание любых колонок, саундбаров и наушников благодаря нативному C++ ядру обработки спектра.

---

## 🆓 Что доступно БЕСПЛАТНО и БЕССРОЧНО (FREE-версия):
Даже когда 5 дней тестового периода истекут, приложение **НЕ заблокируется** и продолжит работать:
1. **Основной переключатель DSP-эффектов** (`DSP Эффекты: Вкл / Выкл`).
2. **Базовый нулевой пресет эквалайзера** (`Сброс 0 дБ`).
3. **Автозапуск вместе с ТВ** при включении приставки (`BOOT_COMPLETED`).
4. **Фоновый защищенный сервис обработки звука**.

## 👑 Что дает PRO-версия (за 390 ₽ один раз и навсегда):
PRO-лицензия разблокирует профессиональные инструменты точной настройки:
1. **Кастомный набор звуковых пресетов** (*Кино, Музыка, Голос, Ночной, W-Shape, M-Shape*).
2. **Ручная 15-полосная точечная подстройка слайдеров эквалайзера** (от 20 Гц до 18 кГц).
3. **Ночной режим сжатия динамического диапазона** (выравнивание громкости взрывов и шепота в фильмах).
4. **Нативный C++ светодиодный спектроанализатор** с субмиллисекундным откликом.
5. **Усиление саб-баса (Sub-Bass)** и пространственная **3D-стереопанорама**.
6. **6 профилей студийной реверберации** и точная подстройка баланса каналов.

*Пользователь может спокойно пользоваться базовым эквалайзером бесплатно всегда, а PRO-версию докупить только если захочет тонко настроить частоты под свои колонки!*
